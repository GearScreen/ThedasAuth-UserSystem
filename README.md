# ThedasAuth User System

-A simpler version of the my [Thedas user system](https://github.com/GearScreen/UserSystem)<br>
-Only use OAuth to register users (doesn't have a custom registering)<br>

## Features

-Signin using Google or Github<br>
-User Sessions<br>
-Store users + custom data in MariaDB<br>

## How to test

Download Repo or git clone<br>
Create GitHub OAuth app<br>
Set .env<br>
docker compose up<br>
